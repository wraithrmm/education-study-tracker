# AQA GCSE Maths — mark-scheme codes and marking principles

Source of truth: the glossary and "principles" pages printed at the front of every AQA GCSE
Mathematics mark scheme (8300). This file reproduces them so marking needs no external lookup.
When a specific mark scheme's guidance differs, the specific scheme wins.

## Mark codes

| Code | Meaning |
|---|---|
| **M** | Method mark — a correct method that could lead to a correct answer. |
| **A** | Accuracy mark — awarded *following* a correct method; the method may be implied (you needn't always see it). |
| **B** | Independent mark — awarded on its own, not dependent on method. |
| **ft** | Follow-through — award for correct working that follows an earlier mistake. |
| **M dep / dep** | Dependent mark — only awarded if the specified previous mark was earned. |
| **B dep** | A B mark awarded only if a previous independent mark was earned. |
| **SC** | Special case — partial credit for a common, mathematically-worthy misinterpretation. The scheme states the exact marks (e.g. SC1, SC2). |
| **oe** | Or equivalent — accept any mathematically equivalent form (e.g. 0.5 for ½). |
| **[a, b]** | Accept any value from a to b inclusive. |
| **[a, b)** | Accept a ≤ value < b. |
| **3.14…** | Accept answers that begin 3.14 (e.g. 3.142, 3.1416). |
| **Use of brackets** | You need not see the bracketed working to award the marks. |

## Marking principles (apply consistently)

- **Positive marking.** Award marks for achievement wherever possible. Credit any valid method, even if not the one printed — if in doubt about an unfamiliar method, seek the underlying mathematics and give credit.
- **Benefit of the doubt.** Where it is unclear whether an answer came from a wrong method, give the student the benefit — unless it is clear the answer came from incorrect working.
- **Diagrams.** Working on a diagram is treated like normal working. If the answer space has the correct response, mark that; contradictory diagram working is not treated as "choice".
- **Misread / miscopy.** If the student genuinely misreads/miscopies a value, penalise only accuracy marks (A or B), to a **maximum of 2**; method marks still stand.
- **Further work.** Once the correct answer is seen, ignore further working — unless it goes on to contradict the correct answer.
- **Choice.** If the student offers a choice of answers/methods, mark each; a wrong answer or method alongside a right one generally loses the mark.
- **Work replaced vs not replaced.** Legible crossed-out work that was *not* replaced is still marked; crossed-out work that *was* replaced is not.
- **Premature approximation.** Rounding too early, causing final inaccuracy, is penalised **1 mark** unless the scheme says otherwise.
- **Show-that / show-working questions.** Marks are usually withheld from students who show no working.
- **Questions not requiring working.** A bare correct answer normally earns full marks.
- **Continental notation.** Accept a comma for a decimal point where the intent is clear.

## Answer-line traps (a frequent source of lost B marks)

Many single-mark questions require the correct value **on the answer line**, not merely in the working. Typical B0 cases the schemes call out:
- Correct fraction/value in working but a wrong or rounded value written on the answer line.
- Right digits but wrong form (e.g. an extra trailing zero when the scheme wants the value as printed, or a decimal where an improper fraction was required).
- A correct probability given as a ratio, or only in words, when a fraction/decimal/percentage was required.

Always check the specific scheme's "Additional Guidance" rows — they enumerate the exact accepted and rejected forms, and often give worked marked examples (e.g. reversed coordinates, wrong unit form) that you can apply directly to a matching student response.
