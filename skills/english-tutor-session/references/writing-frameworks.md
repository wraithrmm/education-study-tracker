# Writing frameworks — the shapes she drills

These are scaffolds, not scripts. Use them explicitly while a shape is being learned, then
withdraw them; the top bands reward fluent, flexible structure, not visible formula.

## 1. What–how–why (analytical paragraph, both subjects)

```
WHAT   [Writer] presents/shows [idea] as [claim using the question's key word]…
HOW    …through "[short quote]" / [close reference], where [method]…
WHY    …which makes the reader [effect] / suggests [meaning] / because [context clause].
DEEPER Zoom: the word "[x]" specifically … | Link: this returns when …
```

Timing: one paragraph ≈ 8–10 minutes at exam pace. A 30-mark Literature answer is four of these
plus a two-sentence conclusion; P1 Q4 is three; P2 Q4 is three (each holding both sources).

## 2. Two-sided comparison paragraph (anthology poetry, P2 Q4)

```
BOTH    Both poets/writers [shared idea], but …
A       In [A], [method] — "[quote]" — [effect].
B       Whereas in [B], [method] — "[quote]" — [effect].
SO      The difference shows [what the comparison tells us about the theme/viewpoints].
```

Connective bank kept small so it's used: *whereas · similarly · both · however · in contrast ·
likewise · while*.

## 3. Evaluate (P1 Q4)

```
CLAIM     I agree that [statement] because …
EVIDENCE  "[quote]" —
METHOD    the writer's use of [x] …
WORKS     … makes the reader [effect], which is why the statement holds / is only partly true.
```

Three rounds; a fourth is a bonus, not a requirement. The verb is *evaluate*: "this works
because", "the writer succeeds in", "the effect on me is".

## 4. Descriptive plan (P1 Q5) — five minutes, on paper

```
MOOD       one word
STRUCTURE  zoom in→out | shift | cyclical | camera-walk
SCENE      1. …   2. …   3. …   4. …
SENSES     for each: one non-sight detail
LAST LINE  written now, before the first
```

Paragraph rhythm: open wide → close on detail → change something → close on a different detail →
return to the opening image, changed.

## 5. Narrative opening plan (P1 Q5)

```
HOOK        first line — action, dialogue or a strange detail
CHARACTER   one, shown through one habit or object
TENSION     what's wrong, implied not stated
STOP        the last line leaves a question
```

## 6. Transactional plan (P2 Q5)

```
FORM / AUDIENCE / PURPOSE
THESIS      one line
ARGUMENTS   1. … (example)   2. … (example)   3. … (example)
COUNTER     "Some say … but …"
CLOSE       call to action / final image
```

## 7. Unseen poem routine (Lit P2 Section C)

```
READ ×2
ABOUT   literal, one sentence
FEELS   tone / feeling, one sentence
THREE   moments where a choice makes that feeling: word · image · structure/sound
WRITE   three what–how–why paragraphs
Q2      similarity in method + difference in method, both quoted
```

## 8. The one-sentence start (blank-page rule)

When nothing is happening: "Write one sentence. Any sentence. It can be wrong." Then "what would
make that sentence more exact?" Momentum first, quality second. Never respond to a blank with a
list of suggestions — respond with the smallest possible next step.

## 9. Self-check card (last five minutes of any timed piece)

- Every paragraph starts with a claim that uses the question's key word?
- Every quote has a method and an effect attached?
- Full stops where I meant them? Any comma splice?
- Did I answer the actual question (re-read it)?
- Literature: is the *writer* the subject of my sentences?
