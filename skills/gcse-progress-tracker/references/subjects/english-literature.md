## Promotion thresholds — band-marked throughout

Every question is level-of-response, so the **band bars** apply:
- `developing`: reaches the band **below** target in a supported attempt (e.g. target Level 5 →
  a Level 4 paragraph with a prompt).
- `secure`: meets the target band **unaided, twice, on different tasks**. Quote the descriptor
  matched in the evidence, never just the mark.
- `examready`: a spaced re-test ≥ 3 weeks later still meets the band.

The exception is **quotation recall** topics (see refs), which are points-marked in starters:
70% supported → developing, 80% unaided → secure.

## Strand and ref scheme (seeded 5–6 Sep 2026; fine-grained x.y refs follow english-literature-syllabus.md)

Refs are **texts and skills**, not chapters. Chip-sized names.

| Strand | Refs (examples) |
|---|---|
| **S** Shakespeare (*Macbeth*) | S1 plot & characters · S2 themes map · S3 quotation bank · S4 extract analysis · S5 whole-play essay · S6 context integrated · S7 AO4 accuracy |
| **N** 19th-century novel (*A Christmas Carol*) | N1–N6 as S1–S6 |
| **M** Modern text (*An Inspector Calls*) | M1–M6 as S1–S6, plus M7 question choice & plan (no extract) |
| **P** Anthology poetry (*Power and Conflict*) | P1 each poem known (15 sub-items or one ref with a `watch` list) · P2 pairings by theme · P3 comparison structure · P4 named-poem close analysis |
| **U** Unseen poetry | U1 reading routine · U2 single-poem analysis (24) · U3 methods comparison (8) |
| **K** Core skills | K1 what–how–why paragraph · K2 embedding references · K3 methods→effects (no feature-spotting) · K4 answering the question set · K5 timed essay stamina (45–50 min handwritten) |

Tag marked questions to the skill the marks were lost to (K3, K4) as often as to the text.

## Behavioural metrics

- **Blanks per paper**, especially the modern-text essay (30 marks, no extract) — should be zero.
- **Quotation recall** — n/5 in starters, per text; trending upward until secure.
- **Timed, handwritten pieces completed** — count per month; stamina for 2h15 is built, not assumed.

## Checkpoint duties — mandatory

- **Dec 2026 — Paper 1 mock (both sections, timed, handwritten):** expect Level 4 paragraphs
  ("clear, explained") in both sections. Below → extend text-knowledge and paragraph work before
  starting the second text.
- **Mar 2027 — full mock (both papers, one attempt):** expect the target band unaided in ≥ 3 of
  5 sections. Flag any section still blank or at Level 2 to the parent in plain words.
- **Entry deadline:** standard AQA summer entries close around **21 Feb 2027** — remind the
  parent when a checkpoint report lands within 6 weeks of it.
- Confirm the June 2027 paper dates with AQA/centre before trusting the tracker `exam_date`.
